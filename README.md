# MY-FIRST-WEBSITE
Welcome to **Fantays Food Hub**,a responsive multi-page web application designed to showcase food services,menus,and contact information. this project was developed as a part of Abuad 105.com to demonstrate core concept in modern front end web design and interactive java script 
  Feature & Technical Highlights
This project meets the required technical standard through the following implementation

6.  contact.html-user inquiry form                                                                                                                   2. Styling and css layout
